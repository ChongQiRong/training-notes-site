Privacy policy

training-notes is a personal application used by its owner only. It is not available to other users.

What it accesses

With the owner's consent it reads the owner's Google Calendar through the Google Calendar API using the read-only scope. It never creates, edits or deletes calendar events.

What it stores

For events in the next 14 days it keeps only the start time, end time and title, on the owner's own home server. Attendees, descriptions, locations and attachments are never stored. Workout data comes from the owner's own fitness watch.

Sharing

Nothing is shared with, sold to or transmitted to any third party. The data is used solely to schedule the owner's own training.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions, after which the application can no longer read the calendar.
